Antigravity && Antigravity IDE && Antigravity CLI ​

ProxyBridge

需要特别注意一个点，当 ProxyBridge 的接管规则配置过于激进时，就会触发之前分析的本地环回流量（127.0.0.1）死锁问题，所以需要添加一条优先级最高的规则。

shell
# HOST
Target IP / Host: 192.168.0.1;127.0.0.1;localhost;::1
Action: Direct / Bypass
